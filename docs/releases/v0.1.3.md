## Syn 0.1.3

A small fix release on top of [0.1.2](https://github.com/azzindani/Syn/releases/tag/v0.1.2).

### Fixed

- **Syn itself could raise a hidden taskbar.** Each time Syn arranged windows (when it starts, when it opens a document in Excel or Word, and from the status menu) it asked Windows to bring its own window to the front. That request comes from Syn's helper, not from the window you are typing in, so Windows refused it and flashed Syn's taskbar button instead, and a taskbar set to hide itself slid up. 0.1.2 stopped the flash of the Office window; this stops Syn's own. Syn is still put in front where it meets the other window, without taking the focus from where you are typing.

### Install

Windows 10 or 11 with desktop Office. Download `Syn-0.1.3-setup.exe` (per-user, no administrator rights) or `Syn-0.1.3-win-x64.zip` (the same files, nothing installed). Add an API key from OpenRouter, OpenCode (Zen or Go) or any OpenAI-compatible provider with the key icon in the sidebar: a key is needed, free models included. The installer is still not signed, so Windows may say "Windows protected your PC": *More info*, then *Run anyway*.

Everything else, including the known limits, is as in 0.1.0.
