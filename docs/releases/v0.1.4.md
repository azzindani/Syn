## Syn 0.1.4

On top of [0.1.3](https://github.com/azzindani/Syn/releases/tag/v0.1.3): the window now follows Syn's work, and Word and PowerPoint no longer raise a hidden taskbar.

### New

- **The window follows the work.** Syn changes documents through the applications' interfaces, which never move their windows, so a column filled at row 50,000, a chart put at S3 or a result on another sheet happened out of sight and a run looked like it was working in the background. After a change the window goes to it:
  - **Excel** brings up the sheet it changed and scrolls the cells, table, pivot, chart or slicer it made to the middle of the window, selected (a drawing by its handles). A block larger than the window goes to the top-left edge; cells in frozen rows or columns are already in view.
  - **Word** scrolls the paragraph or table it wrote into view and selects it.
  - **PowerPoint** goes to the slide it made, changed, duplicated or moved.

  Only the view moves; nothing in the document changes. Checked live: a write at row 200 scrolled to rows 181 to 220, one at AA10 to columns R to AK, a new chart brought its sheet up and selected it, and PowerPoint followed every new slide, format, duplicate and move.

### Fixed

- **Word and PowerPoint could raise a hidden taskbar when they opened.** The helper made each application visible the moment it started, seconds before any document existed. Windows would not let it take the focus from the window you were typing in, so it flashed the taskbar button instead, and a taskbar set to hide itself slid up and stayed up. The frame is now shown without being activated, and any flash is stopped at once. Measured with fresh Word and PowerPoint while typing in Syn: the taskbar used to rise when they opened and stay up for the rest of a 70-second watch; with this build it stayed hidden.

### Install

Windows 10 or 11 with desktop Office. Download `Syn-0.1.4-setup.exe` (per-user, no administrator rights) or `Syn-0.1.4-win-x64.zip` (the same files, nothing installed). Add an API key from OpenRouter, OpenCode (Zen or Go) or any OpenAI-compatible provider with the key icon in the sidebar: a key is needed, free models included. The installer is still not signed, so Windows may say "Windows protected your PC": *More info*, then *Run anyway*.

Everything else, including the known limits, is as in 0.1.0. The follow-along is proven on a real Excel, Word and PowerPoint on one machine; a different Office version or a scaled display has not been tried.
