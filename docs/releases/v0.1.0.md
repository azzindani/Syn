## Syn 0.1.0

The first release. Syn is a desktop agent for one person on one machine: a language model works in the Word, Excel and PowerPoint windows you already have open, and in other windows and web pages, while you watch, interrupt and undo. It reads structure, not pixels: no screenshots and no clicking by coordinates.

### What you get

- **Your open documents.** Syn attaches to the Excel, Word or PowerPoint you have running and edits the document in front of you, or opens files itself. Six operations cover everything: `read`, `write`, `format`, `struct`, `export` and `undo`. `struct` does what you do with the ribbon: rows, sheets, sort, filter, tables, pivots, charts and validation in Excel; paragraphs, tables and contents in Word; slides, text boxes and themes in PowerPoint.
- **Real formulas.** It writes live formulas and reads their results, so a 250,000-row sheet is one call, not a context window.
- **Undo per document**, including in Excel, where changes made from outside normally bypass Excel's own undo. Exports (xlsx, csv, docx, pptx, pdf, png) are copies and never move the file you have open.
- **Other windows and the web.** Any native Windows window through UI Automation; web pages and Electron apps through a Chrome or Edge window of Syn's own, with its own profile. It never types a password or a card number: it asks you to.
- **Side by side, by itself.** Syn takes the right third of the screen and the Office app it is working in gets the rest, edge to edge, so you can watch. This happens when Syn starts and when it opens a document. The status menu changes the side and the share, or turns it off. A window you move yourself stays where you put it.
- **Three ways in.** The console (a window of its own), any MCP client through `mcpgate.exe` (Claude Desktop, Claude Code, OpenCode, Cursor), or the CLI.
- **Your model.** Any OpenAI-compatible endpoint; OpenRouter by default. No key is included: add yours with the key icon in the sidebar.
- **Guarded.** Every call, from any client, goes through one kill switch, an app allowlist, a repeated-call gate and closed schemas. What Syn reads from a document is treated as data, never as instructions. Running a program always stops for your approval, and VBA is off unless you turn it on.

### Install

Windows 10 or 11 with desktop Office. Download one of the files below:

- `Syn-0.1.0-setup.exe`: per-user, no administrator rights.
- `Syn-0.1.0-win-x64.zip`: the same files, nothing installed.

**Windows will say "Windows protected your PC" (Unknown publisher).** The installer is not code-signed yet, and SmartScreen warns about any program it has no history of. Choose *More info*, then *Run anyway*. To not be asked, right-click the downloaded file, open Properties and tick *Unblock* first (for the zip, unblock the zip before extracting it). Code signing is planned: see `docs/code-signing.md`.

Start Syn from the Start menu and add an API key. Setup, configuration and the MCP guide are in `docs/`.

### How it was checked

- On Windows 11 with Office 16: all 270 Office checks of `scripts/live-office-peak.ps1` pass, and so does a 217-operation scripted run across Excel, Word and PowerPoint. The installer was run through its own wizard (install, reinstall, uninstall), and so was the zip. Window placement was checked on a two-monitor setup, including one run where a prompt typed into Syn's window, answered by a real model, opened Excel beside Syn.
- On every push, on Windows, Linux and macOS: clippy and about 650 core tests, the console's browser tests, both Office helpers compiled, and the whole stack running against LibreOffice.

### Known limits

- **Windows only for real use.** The LibreOffice helper exists to test off Windows.
- **Unsigned installer**, hence the SmartScreen warning above. Syn collects no telemetry and sends your documents only to the model endpoint you configure.
- **Excel can stay running.** After a long session an Excel that Syn started has occasionally stayed alive with no document open. It holds nothing of yours and can be closed. The cause is not found yet.
- **Not yet checked:** a Windows 10 machine without the WebView2 runtime, scaled (high-DPI) displays, Claude Desktop itself as the MCP client (a stand-in client was used), and Word or PowerPoint already open when Syn starts (Excel is covered).
- **The browser Syn opens** is not placed beside Syn automatically yet.
