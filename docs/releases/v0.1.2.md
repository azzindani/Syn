## Syn 0.1.2

A small fix release on top of [0.1.1](https://github.com/azzindani/Syn/releases/tag/v0.1.1).

### Fixed

- **An Office window opening could raise a hidden taskbar.** While you type in Syn, an Excel, Word or PowerPoint window that Syn opens cannot take the foreground, so Windows flashes its taskbar button instead. A taskbar set to hide itself slid up and stayed up until you clicked the window, which showed in screen recordings of a typed run. Syn now stops that flash the moment it sees the window, and again while it puts the window in its place, so the taskbar stays hidden and the focus stays where you are typing. Measured with Excel: the taskbar used to rise about 2 seconds after the open and was still up 20 seconds later; with this build it stayed hidden. Word and PowerPoint use the same code but were not opened for the check.

### Install

Windows 10 or 11 with desktop Office. Download `Syn-0.1.2-setup.exe` (per-user, no administrator rights) or `Syn-0.1.2-win-x64.zip` (the same files, nothing installed). Add an API key from OpenRouter, OpenCode (Zen or Go) or any OpenAI-compatible provider with the key icon in the sidebar: a key is needed, free models included. The installer is still not signed, so Windows may say "Windows protected your PC": *More info*, then *Run anyway*.

Everything else, including the known limits, is as in 0.1.0.
