## Syn 0.1.1

A small fix release on top of [0.1.0](https://github.com/azzindani/Syn/releases/tag/v0.1.0).

### Fixed

- **Free models were said to need no key.** The first-start banner, the model picker and the message shown when a model refuses a turn told a new user that models tagged free work without a key, and, when one was refused, to pick another free model. They don't work that way: OpenCode Zen keeps its free models to its own app, and all nine it offered refused Syn when it tried one with no key (checked on 2026-10-18; the error is "OpenCode's free tier can only be used from within OpenCode"). Syn now says a key is needed, and the refusal message says what to do: add a key in Settings (or `AGENT_API_KEY_OPENCODE` for Zen), or use a model from a provider you have a key for. Syn does not pretend to be OpenCode to get past the refusal.

### Packaging and docs

- The zip's `START HERE.txt`, the README and the troubleshooting page now explain the "Windows protected your PC" prompt and how to get past it: *More info*, then *Run anyway*, or right-click the file and tick *Unblock* first (for the zip, unblock the zip before extracting it).
- The README has a code signing policy, and `docs/code-signing.md` says how signing is wired. **The installer is still not signed.** The release build can sign it through SignPath once the project is enrolled, which it is not yet.

### Install

Windows 10 or 11 with desktop Office. Download `Syn-0.1.1-setup.exe` (per-user, no administrator rights) or `Syn-0.1.1-win-x64.zip` (the same files, nothing installed). Add an API key from OpenRouter, OpenCode (Zen or Go) or any OpenAI-compatible provider with the key icon in the sidebar: a key is needed, free models included.

Everything else, including the known limits, is as in 0.1.0.
